Method & QA

This page exists so the table can be challenged. It records how each value was obtained, what was refused, and the result of the automated checks that run after every review.

1. The no-hallucination rule

A value is only published if it was read off a page that was actually retrieved. Each row stores the URL, the UTC retrieval date, and a verbatim quote list in evidence/. The build fails the audit if a quote cannot be found in its evidence file. Anything not on the page is null and appears on the Flagged page. No value is derived by averaging, conversion or “reasonable assumption”.

2. Source hierarchy

  • Tier 1 — product facts: the retailer's own product page (Blue Nile, Zales, VRAI, Brilliant Earth).
  • Tier 1 — policies: the retailer's own return policy page.
  • Tier 1 — gold price: World Gold Council gold spot page, market data by ICE Data Services, with an explicit quote date.
  • Rejected: search-engine snippets, aggregators, blogs, coupon sites, marketplace listings. A snippet is never a source — it was caught disagreeing with the live page three times in this pass (F-004, F-005, F-006).

3. Known limitations

  • LBMA fix data now sits behind an IBA licence, so the free World Gold Council spot quote is used instead (F-013).
  • Brilliant Earth served EUR at retrieval; the USD price is not recorded and was not converted (F-007).
  • VRAI renders its price client-side; the retrieved HTML had no price, so that cell is blank (F-008).
  • Costco was probed and excluded: price and gram weight did not render (F-014).
  • No listing states a hallmark, a maker's mark, or the words “solid gold” (F-001, F-002).
  • Only one item publishes a gram weight, so price-per-gram comparison is not possible for the rest (F-003).

4. Automated checks after every review

Run python3 tools/qa.py (then python3 tools/build_site.py) after any edit. The audit re-reads every JSON file and fails on: a quote missing from its evidence file, a non-null price/weight/width without a supporting quote, a source URL outside the retailer's own domain, a rejected cached value that matches the published value, a flag pointing at a missing item, or a broken internal link in the built site.

## What this audit proves, and what it does not

It proves that every published number is present in the stored evidence for that item, that the source URL belongs to the seller, and that every blank is covered by a flag. It cannot prove the retailer told the truth, and it does not replace an XRF test or an appraisal after delivery.

**Run this again after every review pass.** A stale table is the most likely way a wrong number enters this project.

7. What to do with a flagged row

  1. Open the source link and re-read the price, karat and width yourself.
  2. Ask the seller, in writing: “Is this solid gold (not plated or filled), what is the gram weight, and what hallmark and maker's mark are stamped inside?”
  3. Keep the reply with the order record.
  4. On arrival, before wearing or resizing, have an independent jeweller XRF-test the metal and weigh it.
  5. If the seller will not allow independent verification or a return, do not buy.
