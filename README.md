# GOLD

Evidence-first gold engagement ring research. **No fabricated prices or inferred product facts.**

Site: https://karagemop466-tech.github.io/GOLD2/

## Build / review

```
python scripts/build.py
python scripts/audit.py
node scripts/test.js
```

Dependency-free static dashboard in `site/`. Source data and observed excerpts are generated by `scripts/build.py`. Published facts are dated 2026-10-22 observations, not live prices. Unknown fields are JSON null and rendered blank. Two documented Blue Nile settings do not qualify for purchase: neither has all required evidence. No live gold quote or metal-only weight is verified; calculator intentionally refuses to invent results. There is no claim of a complete market inventory.

Every research table row links official evidence or clearly labeled official context. The checklist is the owner's acceptance policy, not a set of externally verified seller claims. Automated audits run on pushes, PRs and builds, checking sources, null handling, price-excerpt consistency, internal links and static security. They cannot prove facts or detect all hallucinations. Recheck official sources and look for hallucinations after every review. External content may change.

GitHub Actions verifies and publishes `site/` to Pages on main. See COORDINATION.md for ownership, sources and deployment log.
